# DevToolbelt

DevToolbelt is a small desktop app for transforming text and data in your daily workflow.
Paste or type input in the window, pick a plugin, and get the result instantly.
Plugins cover common tasks like formatting JSON, decoding JWTs, hashing lines, and manipulating strings.
Your recent runs are saved in history so you can reuse past inputs and outputs.
More documentation will be added here over time.
